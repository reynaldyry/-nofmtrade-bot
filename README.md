- ℹ️ About
- ⚠️ Risk Warning

## Cara menjalankan

1. Install Python 3.10+.
2. Install dependency:
   `pip install -r requirements.txt`
3. Set environment variable `BOT_TOKEN` dengan token dari @BotFather.
4. Jalankan:
   `python bot.py`

Jangan memasukkan BOT_TOKEN ke source code atau membagikannya.

## Catatan
Bot ini memakai polling, jadi untuk 24/7 perlu dijalankan pada server/VPS/hosting yang selalu aktif.
